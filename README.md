# SahayakAI

AI-powered welfare access intelligence and assistance platform.

## Overview

SahayakAI aims to help users identify relevant welfare schemes,
understand potential access barriers, assess access risk, and
receive actionable guidance.

## Core Pipeline

User Profile
→ Scheme Matching
→ Access Risk Prediction
→ Barrier Detection
→ Recommendations

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend
- FastAPI
- Python

### AI/ML
- Scikit-learn
- XGBoost
- SHAP

### Database
- PostgreSQL
